# AnnounceKit

> AnnounceKit is a product communication platform for SaaS teams. It combines a hosted changelog / release-notes page, 10+ in-app widget types, feature request boards with voting, NPS surveys, and email + Slack delivery in one product. Flat per-project pricing starts at $79/month (billed annually) with unlimited visitors, posts, and team members; 15-day free trial, no credit card required. SOC 2 certified and GDPR compliant. Trusted by 2,000+ teams.

Key facts:
- Founded product category: changelog software / product update tool / release notes software
- Pricing: Essentials $79/mo, Growth $129/mo, Scale $339/mo (annual billing); 15-day free trial
- No MAU-based or per-seat pricing - flat per-project plans
- Integrations: Slack, Jira, Zapier, Intercom, Segment, Google Analytics, n8n, Mailgun, GitHub, WordPress, X (Twitter), Facebook + thousands more via Zapier; full GraphQL API and 11 webhook events
- SDKs: JavaScript widget, React, Vue, Angular, iOS, Flutter, React Native
- Security: SOC 2, SAML SSO, GDPR, DPA available
- Support: support@announcekit.app

## MCP / AI agent access
- [Changelog automation](https://announcekit.app/use-cases/changelog-automation): how AI assistants automate your changelog end to end
- [MCP server docs](https://announcekit.app/docs/mcp): connect Claude, ChatGPT, Cursor, or any MCP client
- Hosted MCP endpoint: https://mcp.announcekit.app/mcp (OAuth login, nothing to install); local: `npx announcekit-mcp` with an ak_pat API token
- Agent capabilities: draft/update/publish/schedule posts, read + reply to feedback and feature requests, read/add roadmap items, read post stats and NPS. No delete or billing actions.
